ON A MAC, DO THIS (about 3 minutes):


      
A · INSTALL

      
    
        
  1. Click the download button above. Wait until the download finishes (the arrow in the top-right of
          Safari/Chrome stops spinning).
    2. 
        
  2. Open Finder → Downloads and double-click the file
          HumanTyper-…-mac-….dmg. A small window opens.
    3. 
        
  3. In that window, drag the Human Typer icon onto the Applications folder icon next to it.
          If it asks to replace an older version, click Replace.
    4. 
        
  4. Close the window. In Finder's sidebar, click the eject ⏏ button next to “Human Typer”.
    5. 
      


      
B · LET macOS OPEN IT (only the first time)

      
    
        
  1. Open Finder → Applications and double-click Human Typer.
    2. 
        
  2. macOS shows “Human Typer” could not be verified (or …cannot be opened because the developer
          cannot be verified). Click Done (or OK).
          Never click “Move to Trash”. The warning only means the app isn't signed with a paid Apple
          developer certificate.
    3. 
        
  3. Click the Apple menu (top-left) → System Settings → Privacy & Security
          (in the left list).
    4. 
        
  4. Scroll all the way down to the Security section. You'll see
          “Human Typer” was blocked to protect your Mac. Click Open Anyway.
    5. 
        
  5. Type your Mac password (or use Touch ID), then click Open Anyway / Open in the next box.
          Human Typer starts.
          Older macOS (Monterey 12 and earlier): Apple menu → System Preferences →
          Security & Privacy → General tab → Open Anyway.
    6. 
      


      
C · GIVE IT PERMISSION TO TYPE (the app guides you)

      
    
        
  1. Human Typer opens a SETUP window with two rows: 1) Accessibility (lets it press keys)
          and 2) Input Monitoring (makes fn+F8 / fn+F9 work).
    2. 
        
  2. Click GRANT on row 1. macOS opens the right settings page with Human Typer already in the
          list: turn its switch on (enter your password if asked).
    3. 
        
  3. Click GRANT on row 2 and turn the switch on the same way.
    4. 
        
  4. Each row turns ✔ granted by itself and the app says All set!. No restart needed.
          Closed the SETUP window? Reopen it with the [ SETUP ] button next to HOTKEYS at the
          top of Human Typer. HOTKEYS: ON means fn+F8 is ready.
    5. 
      


      
D · USE IT

      
    
        
  1. Paste your text into Human Typer (or press ✦ AI WRITE to have it written for you).
    2. 
        
  2. Click into the place you want it typed, like a Google Doc, Pages or a website text box.
    3. 
        
  3. Press fn + F8 to start or stop, and fn + F9 to pause.
          On Mac laptops the F-keys control brightness and volume unless you hold fn. To use plain
          F8/F9: System Settings → Keyboard → Keyboard Shortcuts… → Function Keys → turn on
          “Use F1, F2, etc. keys as standard function keys”.
    4. 
      


      

        Something's wrong? (click here)
        
    
          
  • Nothing gets typed: open [ SETUP ] in Human Typer. Every row must say ✔ granted.
    • 
          
  • fn+F8 does nothing / says HOTKEYS: OFF: Input Monitoring is off (row 2 in SETUP). You can also
            press the ▶ START button in the small floating stats window.
    • 
          
  • Updated from version 1.4.3 or older and the switches are on but it doesn't work: one time
            only, in Accessibility and in Input Monitoring, select Human Typer, click − to
            remove it, then press GRANT in SETUP again. Newer versions keep their permissions when you
            update.
    • 
          
  • SETUP shows ✔ but hotkeys still won't start: click RESTART HUMAN TYPER in the SETUP
            window.
    • 
          
  • “Damaged and can't be opened” or no Open Anyway button: open the Terminal app,
            paste xattr -dr com.apple.quarantine /Applications/HumanTyper.app, press Return, and
            open the app again.
    • 
          
  • It quits unexpectedly: in the crash window click Report…, copy the text and send it to
            us via the GitHub page below.
